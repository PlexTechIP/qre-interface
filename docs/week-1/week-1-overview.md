Week 1 intentionally runs as three independent design tracks. Do not converge
on one layout before the checkpoint; the value is in comparing different
answers to configuration, result interpretation, history, and comparison.

## Required surfaces

Each team designs high-fidelity desktop screens for:

- **Run Configuration** — define a run and launch it.
- **Results Area** — show core metrics, additional metrics, filters, and the
  producing configuration.
- **Run History Area** — view, delete, duplicate, and select saved runs.
- **Comparison page** — compare multiple runs with a table and at least one
  metric visualization.

`week-1-mockup-spec.md` summarizes the assignment. The mockup-spec Google Doc
linked in the project channel is still the source of truth.

## What happens next

After the checkpoint, PMs and the group merge the strongest ideas into one
reference design. That reference design drives week-2 Run Dashboard and
Compare Dashboard implementation, so label screens clearly and make design
decisions easy to lift.

## What week 1 does NOT include

- No code, React components, or Electron scaffold work.
- No real QRE engine spike.
- No persistence/export implementation.
- No requirement to prototype animations or clickable flows in Figma.
